======LIVRARIA======

Description :
LIVRARIA est un mini site web e-commerce spécialisé dans la vente de livres en ligne.

Le site permet :
- de consulter les livres,
- de créer un compte,
- de se connecter,
- de filtrer les livres par catégorie,
- et d’effectuer une commande.
- finaliser la commande
--------------------------------

Instructions d’utilisation :

1. Ouvrir le fichier index.html
2. Accéder a la page d'incription et de connexion avce les boutons connexion et inscription depuis la page d'acceuil
3. acceder a la pages de tout les livres depuis les differents boutons qui se trouvent dans la page d'acceuil
4. Créer un compte ou se connecter
5. Parcourir les livres disponibles
6. Utiliser les filtres de catégories
7. Ajouter un livre à la commande
8.finaliser la commande
--------------------------------
